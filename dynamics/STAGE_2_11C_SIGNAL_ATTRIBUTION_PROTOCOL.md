# Stage 2.11C — Signal Attribution Protocol

## 1. Purpose

This protocol directly tests the unresolved question:

> **Does the biological-state representation contain information specific to the biological process being modeled?**

The protocol is a gate between the existing reproducibility result and any mechanistic or predictive escalation. It is not a mechanism-discovery protocol and it does not reinterpret the historical Stage 2.11C result as causal evidence.

The historical Stage 2.11C result remains immutable. This protocol is prospective and must be committed before its validation datasets are analyzed.

## 2. Competing hypotheses

We explicitly test three non-exclusive explanations for the high trajectory agreement previously observed:

### H1 — process-specific signal

The representation contains a component whose temporal behavior is specific to the modeled process (cell-state reprogramming), and this component generalizes across independent biological contexts better than matched unrelated temporal processes.

### H2 — context/delivery/stress signal

The apparent reproducibility is dominated by context-dependent effects such as delivery, stress, interferon/STAT-like responses, cell-type differences, or other experimental-design effects rather than the target process itself.

### H3 — generic aggregation/representation structure

The high agreement is substantially generated by pseudobulk aggregation, dimensionality reduction, or generic temporal structure of the representation. The same procedure therefore produces similarly high agreement on unrelated temporal datasets.

These hypotheses are not mutually exclusive. The decision gate asks which explanation is sufficiently supported to justify the next methodological step.

## 3. What is being tested

Let `S_d(t)` denote the state representation produced for dataset `d` at time `t`.

The target is **not** simply reproducibility of `S_d(t)`.

We test whether a process-specific information component exists such that:

`S_process(t) = process-specific component + shared/context component + noise`.

The primary evidence must therefore distinguish process labels from nuisance/context labels.

## 4. Required validation design

The audit has four required blocks.

### Block A — independent process replication

Use independent reprogramming datasets that share the target process but differ in biological/experimental context.

Required:

- independent dataset from the original experiment;
- same canonical state representation;
- same preprocessing and identifier namespace rules;
- no threshold changes after inspecting results;
- process-specific outcomes defined before analysis.

The existing GSE297234 time course may be used as the original process trajectory, but it is not by itself sufficient evidence of specificity.

### Block B — matched context controls

The control must vary the suspected nuisance factor while holding the biological target as constant as reasonably possible.

The existing GSE304042 comparison is retained as **heterologous context evidence**, not as a clean delivery-only control. It cannot identify Sendai, Myc, cell type, or any other single factor as the confounder.

A future clean control should preferentially isolate:

- delivery/vector exposure;
- stress/interferon response;
- cell type;
- OSK versus OSKM composition;

rather than changing several of these simultaneously.

### Block C — unrelated temporal negative controls

At least two unrelated biological temporal processes must be processed through the **same representation pipeline** and evaluated with the same trajectory-agreement statistics.

Examples include aging, differentiation, cell-cycle progression, or another time-resolved process that is not a reprogramming experiment.

The exact datasets must be recorded before the analysis is run.

Purpose: test H3. If unrelated temporal processes routinely produce agreement comparable to reprogramming, high correlation cannot be interpreted as process-specific information.

### Block D — nuisance attribution

For each representation component/pathway/TF feature used in the primary analysis, quantify association with:

1. target process/time;
2. known nuisance/context variables;
3. delivery/stress/confounder panels where available.

A feature is not called process-specific merely because it is correlated with time.

## 5. Primary metrics

All metrics are calculated from predeclared feature families. No feature family may be added after inspecting outcomes.

### 5.1 Process discrimination

Evaluate whether the representation distinguishes process samples from matched controls under cross-validation.

Primary metric:

- AUROC, with a prespecified null/permutation reference;
- secondary: balanced accuracy.

The classifier must be trained without leakage across biological replicates/datasets.

### 5.2 Process-specific temporal agreement

For independent process datasets, calculate the same trajectory agreement statistic used previously, but compare it with the distribution obtained from unrelated temporal negative controls.

Primary quantity:

`Δ_process = observed process agreement - median unrelated-process agreement`.

A positive raw difference is descriptive only. The decision must use a prespecified permutation/block-bootstrap reference.

### 5.3 Nuisance attribution

For each candidate representation feature, report standardized association/effect with:

- process label;
- delivery/context label;
- stress/interferon/STAT panel score;
- cell type;
- perturbation composition (OSK/OSKM where available).

No single nuisance source may be declared causal unless the design isolates it.

### 5.4 Residual process signal

Where a nuisance variable is measurable, fit a prespecified residualization model and repeat the process-discrimination test on the residual representation.

Residualization is an attribution sensitivity analysis, not proof that the nuisance variable caused the original signal.

## 6. Null and permutation structure

The permutation unit must be the biological replicate/dataset block, never individual cells when pseudobulk/sample-level data are used.

For classification:

- permute process labels within the prespecified exchangeability blocks;
- preserve dataset/replicate structure;
- use a fixed random seed;
- report the full empirical null distribution and exact attainable p-value resolution.

For trajectory agreement:

- preserve each dataset's internal temporal structure;
- permute only the relationship between process labels and trajectories under the declared null;
- do not reuse the four-time-point exact permutation rule as if it were sufficient for the new question.

Multiple candidate-level inferential p-values must be corrected with Benjamini–Hochberg before feature-level significance is interpreted.

## 7. Pre-specified decision gate

The result must be assigned exactly one primary decision.

### A — `SPECIFIC_SIGNAL_SUPPORTED`

Assign only if all are true:

1. process discrimination is above the predeclared null threshold in an independent validation design;
2. process-specific temporal agreement exceeds the unrelated temporal-control distribution by the predeclared margin;
3. the effect remains materially present after the prespecified nuisance sensitivity analysis;
4. no single known context/delivery signal explains the majority of the observed process-discriminative signal;
5. the result survives BH correction for the declared inferential feature family where feature-level inference is performed.

This decision permits a prospective V2 validation study. It does **not** establish causality.

### B — `CONFOUNDER_DOMINANT`

Assign if the majority of the reproducible signal is attributable to a measurable nuisance/context axis and the process-specific residual signal fails the A criteria.

This decision requires redesign of biological controls before mechanistic or predictive escalation.

### C — `AGGREGATION_ARTIFACT_PLAUSIBLE`

Assign if unrelated temporal negative controls show agreement comparable to the target process, or if the apparent process signal disappears under a prespecified aggregation/representation sensitivity analysis.

This decision requires representation redesign before further biological interpretation.

### D — `SIGNAL_UNRESOLVED`

Assign if A/B/C cannot be distinguished with the available controls, sample structure, or inferential resolution.

Under D, **do not proceed to mechanistic claims or prediction**.

## 8. Stopping rule

The methodological class is stopped, rather than repeatedly patched, if two consecutive prospective validation designs fail to distinguish the target process from either nuisance/context or unrelated temporal controls under their locked decision criteria.

A failure cannot be converted into success by changing thresholds, swapping negative controls, or changing the representation after seeing the result. A new representation constitutes a new methodological proposal and requires a new protocol.

## 9. Reproducibility lock

Before a prospective run, persist:

- exact input dataset identifiers and file hashes;
- exact Ensembl→HGNC mapping table when mapping is required;
- annotation/mapping service version where available;
- preprocessing parameters;
- representation/network versions;
- random seeds;
- feature-family definitions;
- classifier specification;
- permutation/block definitions;
- decision thresholds;
- output manifest.

A filesystem modification time alone is not an execution log.

## 10. Interpretation guardrails

The following claims remain forbidden from this stage alone:

- “the representation is causal”;
- “the representation identifies the mechanism”;
- “Sendai is the confounder” unless an isolating control demonstrates this;
- “high correlation proves biological specificity”;
- “prediction is justified” when the specificity gate is unresolved.

The desired scientific conclusion is narrower:

> **A state representation is process-specific only if its information discriminates the target process from matched nuisance/context variation and from unrelated temporal structure under a locked validation design.**

## 11. Status of current evidence

Current Stage 2.11C evidence does not yet satisfy this protocol because:

- the 0.92/0.96/0.98 reproducibility results were not compared against unrelated temporal negative controls;
- the GSE304042 comparison is heterologous and cannot isolate a unique confounder;
- the historical 1/28 Tier-B candidate was not a direct test of whole-representation process specificity;
- the saved Null-1 analysis contains inferential p-values whose BH reanalysis eliminates global significance, but this is a reclassification of the same experiment, not an independent experiment.

Therefore the present status is:

`SIGNAL_ATTRIBUTION_PENDING`

No predictive or mechanistic escalation is justified until this protocol's design blocks are executed or a documented design limitation makes a different decision unavoidable.
